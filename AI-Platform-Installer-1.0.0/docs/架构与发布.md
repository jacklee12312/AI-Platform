# 架构与发布

## 数据与执行路径

安装器读取 `catalog/release-catalog.json` 并验证 Ed25519 签名，读取可编辑的来源配置，再按缓存、本地源和远端顺序取得内容。签名清单包含 277 个资源、64 个模型文件、26 个模型/服务条目，以及平台、Docker、运行时和镜像四类组件。

资源依次进入摘要缓存；全部获取并验证后，组装到 `/var/lib/ai-platform-installer/private/releases/<release_id>/resources`。随后使用已修正的正式安装引擎执行资源复核、运行时展开、冲突检查、Docker 配置、文件安装、凭据生成、镜像导入、服务注册、启动和验收。

缓存文件按 SHA-256 寻址，重复使用同一内容时无需重新下载。每次开始仍校验缓存内容；暂存目录采用硬链接节省空间，跨文件系统时安全复制。后台状态含具体阶段、当前文件、处理字节和错误，公开报告不包含密码、来源令牌或 API 密钥。

0.2.2 支持模型 OCI 工件的匿名 Harbor 拉取和安全解包，25 个仓库覆盖全部大型模型文件；详见 [Harbor 下载接入](Harbor下载接入.md)。容器镜像仍使用原独立镜像归档。所有正式下载地址只从 `sources.json` 读取。平台内置的历史模型目录随已锁定平台版本保留，以维持服务兼容；安装器不会调用这些历史地址。以后如升级平台内的模型管理功能，需要同时发布匹配的平台代码与镜像。

## 模型、组件和地址的边界

`release-catalog.json` 是不可变内容定义，包含大小、摘要、类别、模型归属和相对路径。`sources.json` 是可修改的获取位置。换服务器、使用多个镜像源或改成本地缓存，不改变安装的实际内容。

平台核心代码约 2 MB，Docker DEB 约 79 MB，配套运行时归档约 864 MB，12 个镜像的独立归档约 2.51 GB。它们都独立于模型文件；本版暂以每个既有资源文件为下载单元，没有把镜像重新封装成 OCI Registry。

服务、模型挂载与运行参数继续采用已验证的 `/home/cix` 配置。这里的版本目录是资源暂存和安装事务记录，不代表已经实现在线多版本切换或自动回滚。加速卡模式互斥，未来升级方案需要显式处理停机、数据库迁移和旧版本恢复。

## 发行签名

本次使用本地生成的开发 Ed25519 密钥。私钥存放在构建机 WSL：

```text
/home/lenovo/.local/share/ai-platform-release-keys/development-ed25519.pem
```

私钥不在 U 盘安装器、资源库或 `.run` 中。交付目录只含公钥及签名。正式发布应使用项目正式发布密钥，并通过可信交付渠道确认公钥指纹；当前开发签名不代表公司正式发布授权。

更改来源地址不需要重签。更改模型版本、资源摘要、组件内容或硬件约束后，需要重建目录并签名：

```sh
python3 tools/sign_release.py --key /受保护目录/正式私钥.pem
python3 tools/seal_installer.py
```

独立 `.run` 由同级构建目录中的 `pack_launcher.py` 生成。它是带 Python 入口的 ZIP，第一次运行只展开轻量安装器到用户缓存；不包含模型或平台大型资源。旁边的 `.sources.json` 可以单独修改，之后无需为地址变更重新制作 `.run`。

## 验证与后续工作

`docs/evidence` 保留 Linux 测试、真实本地 HTTP 下载测试、安装引擎隔离集成测试和 ARM64 Qt 预览证据。隔离集成测试实际执行资源获取、资源校验、归档展开、文件复制和凭据初始化；Docker、systemd 与硬件推理由测试替身处理，不算真实盒子安装。

后续收到远端地址后，填写来源配置，并验证服务器的实际下载、断点和完整文件摘要。正式交付前还需在兼容物理盒子上完成空白部署、全模型真实验收及断网重启。升级、自动回滚、卸载、定时/限速下载、部分模型部署与容器镜像 OCI Registry 接入属于后续功能，不在本版界面中提供未实现的选项。
