# 安装与来源配置（0.2.3 预览）

## 交付与配置位置

保留轻量安装器和同级 `AI-Platform-ResourceStore-20260921` 平台资源库。25 个模型仓库均已配置，包含 CosyVoice3 和 Spark；没有 U 盘模型权重时会从 Harbor 下载。旧包 `AI-Platform-Offline-GUI-20260919/resources` 仍可作为可选的本地优先来源。

文件夹版使用 `sources.json`；独立版优先使用旁边的 `AI-Platform-Installer-0.2.3-linux-arm64.sources.json`，没有旁边的配置时使用内置默认配置。向导不再暴露高级 URL 表单；模型源固定为“联网下载”或“本地导入”。需要更换仓库地址时可编辑独立版旁边的来源配置文件。

模型来源由 `model_source` 控制，值为 `online`（默认）或 `local`。有效缓存始终优先。平台组件继续由 `mode=prefer-local` 从同级资源库取得；平台代码、Docker、运行时和镜像尚未配置远端地址。

默认本地目录：

```json
"local_roots": [
  "@bundle/support-files",
  "../AI-Platform-ResourceStore-20260921",
  "../AI-Platform-Offline-GUI-20260919/resources"
]
```

`@bundle/` 永远相对于实际安装器文件夹，支持独立入口解包后的辅助文件。其他相对路径按安装介质位置解析。本地目录支持 `files/<资源路径>`、旧包原始资源布局和 `blobs/sha256/<摘要>`。

## Harbor 来源

`oci_artifacts` 已填入 25 项，每项含：

- `registry`、`repository`、`reference`：服务、仓库、原始标签。
- `manifest_digest`：实际使用的固定清单摘要，不跟随可变标签。
- `blob_digest`、`blob_size`：资源层摘要与大小。
- `format`：`blob` 为原始文件，`tar+gzip` 为压缩目录。
- `files`：发行资源路径到归档成员的映射；原始文件的成员值为 `null`。

通过只读 Registry API 获取匿名 Bearer 令牌，令牌只留内存，不依赖 ORAS。当前来源为 HTTP，因此 `allow_http` 为 `true`。改 HTTPS 时须先更新真实服务地址。私有账号登录尚未实现；跨服务重定向会拒绝，避免转发令牌。

不能只改标签来更换模型内容。换版本必须重新核对清单与文件摘要；不能关闭校验绕过不一致。

普通直链机制 `base_urls` / `file_urls` 仍可在配置文件中使用。根地址指向含 `files/<资源路径>` 的目录；查询参数链接应填进 `file_urls`。向导主页面不显示这些高级设置。

## 缓存、空间和恢复

文件及压缩层进入 `/var/cache/ai-platform/blobs/sha256`。下载失败保留 `.part`，服务器支持 Range 时续传。压缩层验证完整摘要后仅读取指定普通文件，按原签名发行清单检查大小和 SHA-256；不执行压缩包内代码，不跟随链接，不按未可信路径直接解压。

所有资源齐备并验证后才部署平台。关闭界面不终止后台任务。失败后可以修改来源并继续。镜像导入和模型验收在安全边界响应暂停。

原全本地方案建议同分区至少 160 GB。6 个目录包均从远端取得时额外保留约 8.15 GB 压缩层，建议至少 170 GB；跨分区可能更多。后台按实际文件系统合并预算后检查。

## 离线预取

在 Python 3 + OpenSSL 的 Linux/WSL 环境运行：

```sh
python3 tools/resource_manager.py plan --output /某磁盘/AI资源库
python3 tools/resource_manager.py fetch --output /某磁盘/AI资源库
```

支持混合本地和 Harbor 来源，不部署服务。输出的摘要缓存可作为离线来源。`--models` 限制预下载范围。图形向导的勾选项另会限定实际模型权重部署和真实推理验收；平台基础组件与固定 12 镜像归档仍完整安装。
