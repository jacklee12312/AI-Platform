# 0.2.3 按需模型安装验证状态

本版保留 2026-09-21 的 Ed25519 签名资源发行清单，安装器在内存中按勾选项生成资源子计划，不修改原签名清单。平台、Docker、运行时和固定 12 镜像归档仍完整安装；未选模型的权重文件不进入获取、校验或部署计划。

本地验证：Linux 单元/集成测试 87 项通过；QEMU Debian 12 ARM64 / Qt 6.7.3 图形测试 16 项通过，7 个向导页面均可截图。单模型 `copaw-flash-9b` 的来源计划包含 213 个平台文件和 1 个模型权重，其他模型权重不在计划内；使用同级资源库时来源计划就绪。模拟安装任务确认未选模型文件未复制到目标目录。

尚未验证：在全新物理盒子上完成所选模型的下载、容器启动、真实推理和断网重启。因此 0.2.3 仍是开发预览，不能视为现场安装验收通过。

界面限制：当前平台的开机服务至少需要一个 LQ50 主模型。CosyVoice3 单独勾选时会随包带入用于真实语音验收的小型测试 WAV，不安装 SenseVoice 权重或服务。使用“本地导入”时仍须提供平台资源库；模型文件须与签名发行清单的 SHA-256 完全一致。
