# 单双卡自动选型

安装器检查 `/dev/aipu` 和 XH2 设备 0 的关键字符设备，再检查设备 1 的完整节点组。设备 1 全部缺席识别为单卡，全部存在识别为双卡，只出现部分节点则阻止安装。检查页显示识别结果；后台任务重新检测并与提交时记录的卡数比较，防止检查后硬件状态变化。

| 单卡 | 2026-09-11 `1d-xh2`，20.70 GB + 视觉投影 3.01 GB | 设备 0，HLIELLama 2.2.0，128K，文本与图片 | 真实文本及图片推理 |
| 双卡 | 2026-09-11 `2d-xh2`，21.10 GB，加动态视觉投影 3.01 GB | 设备 0/1，HLIELLama 2.2.0，256K，图文 | 真实文本与图片推理 |

Qwen3.8 是本版唯一同时收录单卡和双卡权重的现有模型。其他模型沿用其已适配权重。下载、缓存和本地导入都按所选卡数筛选签名发行清单；不会准备另一种卡数的 Qwen3.8 权重。单卡与双卡运行配置也是发行清单内分别校验的文件。

U 盘离线来源需要在 `AI-Platform-Model-Library/files` 下保存两种权重及共用的视觉投影。两种权重的厂家 HTTPS 地址均已写入 `sources.json`；联网模式会按需下载并核验 SHA-256。
