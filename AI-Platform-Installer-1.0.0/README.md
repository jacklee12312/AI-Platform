# AI 平台安装器 1.0.0

适用环境：厂家 Debian 12 ARM64、Python 3.11、CIX P1、后摩 LQ50/XH2 v1.4.0 驱动，支持一张或两张加速卡。

本版提供 27 个模型及服务选项。单卡设备可选其中 26 项；Qwen3.6-35B-A3B 仅在双卡设备上可选。平台包含 Docker 29.7.2、配套 Compose、12 个锁定镜像、运行时、API 网关和管理中心。

## 启动安装

将整个交付目录复制到目标设备，不要只复制 `.run` 文件：

```text
AI-Platform-1.0.0-linux-arm64/
├── 安装AI平台.desktop
├── 安装AI平台-1.0.0.run
├── 安装AI平台-1.0.0.sources.json
├── support-files/
└── README.md
```

建议将交付目录放在用户主目录，双击 `安装AI平台.desktop` 即可打开图形安装界面。首次双击如提示是否信任或允许启动，请选择允许启动。也可以将该桌面文件复制到桌面，仍会打开主目录中的交付包。

也可以在图形桌面的终端中运行：

```bash
python3 ./安装AI平台-1.0.0.run
```

默认选择“联网下载”。向导依次执行设备识别、模型选择、来源和环境检查、账号设置、资源下载及校验、安装、真实推理验收。下载支持断点继续，下载完成并通过 SHA-256 校验后才进入部署。

本版用于全新安装和同一任务的失败恢复。已有平台部署、不同版本安装记录或内容冲突会明确报错。

## 按卡数自动选型

| 模型 | 单卡设备 | 双卡设备 |
|---|---|---|
| Qwen3.8-27B 多模态 | `aistore/qwen3-8-27b:v1`，128K | `aistore/qwen3-8-27b-2:v1`，256K |
| Qwen3.6-35B-A3B 多模态 | 不可选 | `aistore/qwen3.6-35b-a3b-2:v1`，256K |
| 其余原有模型 | 使用现有适配版本 | 使用现有适配版本 |

仓库统一为 `36.111.34.121:15436`，按指定的 plain HTTP OCI 协议拉取，等效于 ORAS 拉取制品中的已锁定资源层。主 GGUF 和对应 mmproj 都必须存在。Qwen3.8 不再使用旧厂家 HTTPS 下载链接。

设备识别检查 XH2 设备节点；第一张卡不完整、第二张卡部分缺失或检测到超过两张卡时停止安装。检查页、提交安装任务和后台工作进程分别确认卡数，防止界面记录与实际设备不一致。其他只提供单卡版本的模型仍按单卡运行。

Qwen3.8 使用 HLIELlama 2.2.0；Qwen3.6 双卡使用已打包的 HLIEvLLM 1.4.0-0825hsc、插件及 TCIM 1.4.0。以上是推理运行时，设备应已有匹配的 XH2 驱动。加速卡主模型通过管理中心互斥切换。

## 本地导入

选择包含 `model-library.json` 和 `files` 的 `AI-Platform-Model-Library` 顶层目录。模型库可跨发行日期复用，文件必须符合本安装器锁定的大小和 SHA-256；本地缺文件时会提示。

## 仓库上传与验收状态

构建期间，三个新仓库尚在上传。上传人员应按《模型上传清单》将主模型和 mmproj 作为原始 GGUF 文件层上传至同一个 `v1` 制品。安装器按签名清单锁定文件摘要，上传正确文件后无需重做安装器。

仓库返回 404、缺少 GGUF 层、摘要不一致、鉴权失败或网络不通，都会在检查或资源准备阶段提示；不能跳过校验继续安装。

完整验证范围以《验证报告》为准。容器验证、自动化测试不等同于全新机器完整安装及重启验收；后两项须在实际交付设备执行，安装器只有现场验收成功才显示完成。

## 安装后入口

- 管理中心：`http://设备IP:17780/`
- OpenAI 兼容 API：`http://设备IP:17700/v1`
- 管理员密码由安装时设置；API 和 Agent 密钥独立生成。
- 安装日志和失败诊断可在向导中导出。

本包不包含大模型权重，模型通过所选来源按需获取。`support-files` 是必要的平台和运行时资源，须与安装器一起分发。
