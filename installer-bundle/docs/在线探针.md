# 在线获取探针

探针阶段对 `http://36.111.34.121:15433/api/liuer/ops/probe-package/download` 发起新的 GET 请求。安装包不携带探针程序归档；原签名 workflow.json 中的 1.1.2 条目保留为历史资源记录，不用于当前版本选择或摘要比较。旧交付文件保持原始字节。

下载完整后检查包结构、必要文件、解压大小和 Linux ARM64 ELF 类型。安装器只提取程序、服务和证书，不运行上游 install.sh，也不导入上游预置绑定配置。记录本次下载时间、版本名、资源包及二进制 SHA-256；版本名相同但二进制摘要不同也会触发替换。

- 本机程序与本次下载的程序摘要一致：直接复用，保留注册配置。
- 本机程序摘要不同：备份原程序、服务和配置，只发布新程序和服务；保留设备注册信息，注册和 MQTT 检查通过后提交。失败恢复原程序和配置。
- 本机没有探针：使用本次下载的程序，现场填写注册配置并通过注册和 MQTT 检查。
- 接口、网络、包结构或架构检查失败：停在探针阶段，不使用旧包内版本代替，不进入组件和模型安装。继续安装时重新获取接口当前版本。

GUI 只识别是否已有探针并隐藏已有设备的注册表单；摘要比较由正式后台在下载后执行。首次安装及失败后继续都需要下载接口可用，即使模型选择本地导入也是如此。

下载来自指定发布接口；本次计算的 SHA-256 用于程序比较、完整性记录和诊断，不应被解释为独立发布者签名。当前兼容 data-probe-offline 目录结构及现有系统服务接口，未来不兼容的上游包会明确停止，避免部署半成品。
